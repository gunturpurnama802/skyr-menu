# SKYR Menu

Menu digital QR SKYR Cafe — Pure HTML, CSS, JS + SQLite & Static JSON.

## Fitur Customer:
- **Welcome Screen**: Animasi pembuka & maskot waving lottie.
- **Background Music**: Random picker (`fh.mp3` & `jb.mp3`).
- **Menu & Filter**: Filter kategori menu & catatan pesanan (bucket drawer).
- **Statis & Ringan**: Bisa di-host langsung di GitHub Pages atau server VPS.

## Jalankan Lokal:
```bash
node server.js
```
Akses di browser: `http://localhost:5000`
